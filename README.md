# Coen ten Thije Boonkkamp

**Lawyer • Legal Engineer • Software Developer**

I see a future where economic differences no longer dictate legal outcomes. To reach that future, we need technology that makes legal services accessible and affordable.

Another reality is that the infrastructure to reach this just isn't there yet.

That's why I build the [Swift Institute](https://github.com/swift-institute) ecosystem: layered, convention-driven Swift infrastructure across [swift-atoms](https://github.com/swift-atoms) and [swift-molecules](https://github.com/swift-molecules) (atomic building blocks), [swift-standards](https://github.com/swift-standards) (specification implementations), and [swift-compositions](https://github.com/swift-compositions) (composed systems — I/O, filesystem, HTML, CSS, PDF, networking). Strict memory safety, typed throws, and compile-time guarantees that hold across package boundaries.

Legal technology is where this work is headed — the infrastructure below is how it gets there. [Rule Institute](https://github.com/rule-institute) encodes law as typed Swift, starting with Book 2 of the Dutch Civil Code (company law); the code is private, and I'm happy to demo it.

## Selected work

The Swift Institute ecosystem is in public alpha — released repository by repository.

| Project | What it is |
|---|---|
| [swift-pdf](https://github.com/swift-compositions/swift-pdf) | PDF generation from HTML views and Markdown — successor to swift-html-to-pdf |
| [swift-html](https://github.com/swift-compositions/swift-html) | Type-safe HTML, CSS, and SVG, grounded in the WHATWG and W3C specs |
| [swift-file-system](https://github.com/swift-compositions/swift-file-system) | Typed filesystem operations — scoped handles, atomic writes, zero-copy reads |
| [swift-io-kernel](https://github.com/swift-compositions/swift-io-kernel) | Async I/O executor isolating blocking syscalls — benchmarked against NIOThreadPool |

Earlier server-side Swift work — [swift-records](https://github.com/coenttb/swift-records), [swift-stripe](https://github.com/coenttb/swift-stripe), and the production server behind [coenttb.com](https://coenttb.com) — still runs in production today.
